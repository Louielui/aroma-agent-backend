# Investigation quality and efficiency v1

The existing read-only investigation stays responsible for goal understanding,
authorised source selection, one bounded continuation and exact evidence grading.
This delivery measures phases, makes fixed failure reports concise, and removes
unused answer/review calls from one additional provably bounded presentation.

## Fixed revision continuation

A fresh work-failure investigation may use the existing fixed-answer guard after
one GitHub follow-up pinned to the exact target source revision. All required facts
must still use local operations. Extra plan facts may only name enriching GitHub
or development_record evidence; the latter's unavailable integration remains a
stated gap. Both names describe the same revision-only continuation, never a
broader repository or test-results search.
Required external facts, arbitrary GitHub searches, unresolved required facts,
continuity, ambiguous records, conflicting assertion evidence, actions and general
investigations retain the model/review path. A revision sample is not repair proof.
Empty/unavailable revision probes remain distinct and never cause recency fallback.

## Owner report and measurement

Fixed failed-work findings produce a short recorded reason, an explicitly unknown
current repair outcome and a read-only recommendation. Known failure codes have
bilingual explanations; unknown codes are kept in the evidence rather than given
an invented diagnosis. Exact references, detailed source checks, missing sources,
contradictions, tests and version comparisons remain in the saved report and the
collapsed investigation panel. The original receipt is never overwritten by a brief.

Operational reads and actual semantic-review calls join existing goal, main answer
and final-verifier timings. Saved performance fields are metadata only. Nested
prompt phases cannot be added to prompt_build; the provider invocation ledger is
authoritative for actual provider-call counts. Total intake time excludes HTTP and
post-intake persistence. The stop state means the authorised bounded plan finished,
not that every fact is proven or that all possible sources were searched.

## Acceptance

Exercise Chinese/English paraphrases through the same source-routing architecture;
development failure/current repair, background models/current activity, cost/usage,
missing evidence, outage, empty results, conflicting/duplicate identities, denied
sources, required external evidence and prior-investigation continuity. Verify no
extra management tasks, unchanged unknown outcomes, exact-revision follow-up once,
explicit coverage gaps, durable performance/brief receipts and collapsed evidence.
Use loaded-route observations for latency, not unit-test clocks or promises of speed.

Provider billing, complete external worker inventory and same-failure regression
proof remain partial/unconnected where evidence is absent. No action permissions,
provider selections, subscription defaults or background schedules are changed.
