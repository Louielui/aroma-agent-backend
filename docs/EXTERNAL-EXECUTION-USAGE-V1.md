# External execution and usage evidence v1, slice 1

This read-only slice consumes the existing registered Owner metadata readers. It
does not enumerate new filesystem roots, grant access, invoke workers, change
models or connect account billing. No provider prices are used.

## Identity and coverage

Bridge invocation IDs identify attempts. Only validated host request IDs with the
host identity basis group phases. Multiple phases are not proof of retries.
Identical receipts count once; conflicting identities are withheld. Unlinked
memory calls remain lane calls, not named emails, schedules or workers.

Codex session IDs identify registered project sessions. Unique turn identifiers
provide observed start/completion counts. Sampled files, invalid lines or missing
turn identifiers leave count completeness false. Source enumeration and sampling
coverage are retained, so absence in a sample never establishes absence globally.
Worker records provide recorded work state only. Direct worker call linkage and
external scheduler execution witnesses are still unconnected.

## Usage

Provider model-result counters may be subtotaled within distinct invocation IDs
for the same host request and provider/model. Counter coverage is retained per
field; absent counters are not zero. Primary model and helper usage are separate;
the primary entry in usageByModel is not added again to its top-level copy.
Contradicting copies are withheld. Safe-integer overflow remains unknown.

Last-turn counters are retained per call without being summed into a request
total. Each Codex session keeps its latest observed cumulative snapshot, not the
sum of snapshots. Context model selection does not attribute session-wide tokens
to one model. Session and bridge usage are never added together. Failed or
interrupted calls may have consumed unobserved usage; successful sampled calls
cannot establish full request coverage or account totals.

## Delivery acceptance

Controlled adapter and provider-receipt tests cover exact identity, duplicate and
conflicting receipts, partial failures, helper models, last-turn scope, cumulative
snapshots, malformed counters, missing source coverage and bilingual fixed cost
answers. Loaded-service questions and saved reports are verified separately.

Billing, subscription credit consumption and execution-to-charge correlation are
not established. Future official billing/usage adapters must preserve their own
account scope and correlation granularity; aggregate bills cannot prove a
particular job caused a charge.
