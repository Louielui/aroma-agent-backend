# Public Answer Quality and Efficiency v1

## Measured defects and boundaries

The recorded Chinese library draft translated the host-generated `unknown, not
closed` coverage line as `unconfirmed, not a closure`. The lexical guard withheld
that line while the host separately printed the same limitation. This was a
redundant scope translation, not missing evidence for the listed intervals.

The next real baseline returned only the library directory and older announcements,
not the canonical branch page. It correctly returned an incomplete result, taking
93.5 seconds with two compositions. The English weather and release baselines took
73.6 and 71.2 seconds. These are samples, not latency guarantees.

## Changes

- An exact host-generated structured coverage quote is discarded as
  `hostScopeHandled`, and canonical scope is rendered from metadata. The discarded
  model wording is never published, whether honest or false. Other withheld claims
  retain closed reason counts. Recurring facts cannot assert date-specific closure
  merely by adding an unrelated `unknown` clause.
- Verified quoted recurring intervals from a single source become a weekday-ordered
  table. Missing days remain unknown, never fabricated table rows. Other summaries
  retain the normal requested-language rendering. Scope, omissions and unknown
  timing remain visible; implementation notes, checks and excerpts are collapsed.
- The registered official library directory exposes observed canonical branch
  links. Only one branch name explicitly present in the approved public query is
  eligible. Ambiguous/unnamed queries do not select a branch. A branch read and its
  JSON reference share the existing two-extra-read cap; no URL guessing, scripts,
  account access or extra permissions are introduced.
- A prepared source-bound public final can replace the unused post-read model
  answer only when the existing semantic world obligation is public-only, the
  public world is complete, there are no internal rows or operational investigation,
  and every summary is supported, in the correct language, with publisher hashes.
  The existing terminal gate still judges it. Unknown, mixed, failed, uncomposed and
  search-summary-only results retain normal reasoning. No keyword intent router.
- Public authentication, discovery, publisher reads, reference/alternate reads and
  composition now use the existing monotonic phase timer. Closed role/outcome
  records contain no query, source text, URL or provider exception. Failed stages
  remain measured. Receipts distinguish source-phase elapsed time from whole-turn
  time and preserve original timings on cache reuse.
- A numeric-only translation failure may use one repair composition limited to
  its original exact quote. Successful replacements preserve other verified facts.
  Repair and insufficient-evidence recomposition share a two-composition cap and
  the same deadline. Failure retains the partial answer and observed retry usage;
  there is no recursive repair or relaxation of the numeric guard.

Runtime brain remains Claude Opus 5.5 / medium. Public retrieval/composition retain
their existing Opus / low worker settings. No provider fallback, API billing proof,
general renderer, account connector or write capability is added. The source
catalogue and 110-second source-phase deadline remain unchanged.

## Verification

RED-first tests cover the recorded scope translation, false closure withheld in
favour of host scope, counted numeric rejection, named/ambiguous directory links,
weekday table facts, guarded prepared finals through real intake, terminal refusal,
mixed/insufficient cases, content-free timing and observed usage preservation.
Actual Express/Claude/public GET samples and loaded Owner UI proofs are stored
separately; tests do not establish loaded runtime behaviour.

Measured candidate cases: Chinese regular hours 91.3 s, English weather 54.6 s,
English release listing 55.1 s, English regular hours 69.6 s, Chinese weather
86.0 s (one correctly withheld added date), and Chinese release listing 65.9 s.
Chinese weather subsequently returned all three quoted summaries in 77.2 s.
An actual tool-free repair of the recorded bad numeric translation also passed;
its first separate probe was unavailable and is not counted as a pass. The latter
repair uses recorded source quotes, not a fresh search or deployment proof.

The English weather and release samples improved from 73.6/71.2 s to 54.6/55.1 s.
These are individual before/after samples with mutable sources and model timings,
not a guaranteed speedup. The structural improvement is one avoided unused answer
call on qualified public turns; a numeric repair can spend that saving on another
composition. Authentication/routing/planning costs remain. Generic correctness,
all library branches and arbitrary publishers are not established by these cases.

Final suite: 7,454 passed, 5 skipped, no failures. An earlier full run failed the
unchanged parallel approval-event writer test (180/200 records); the isolated
10-test recheck and the subsequent full suite passed. No store code was changed,
and this does not establish the cause of that transient failure.
